Нужно на golang сделать программу по следующим критериям.
Краткое описание программы: показывать список файлов *.json с возможностью их редактирования, где каждый элемент редактируется с помощью формы.
1. Консольное приложение с текстовым пользовательских интерфейсом
2. Для построения интерфейса использовать библиотеку "github.com/rivo/tview"
3. В левой части приложения должен быть список выбора файла для редактирования. Список должен занимать не более 1/3 экрана по горизонтали.
4. В правой части приложения должна быть форма редактирования элемента. По размеру не более 2/3 экрана.
